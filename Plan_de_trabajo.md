# Plan de trabajo



* #### Planificación del proyecto



Para el desarrollo conceptual del Sistema de Gestión de Inventario y Recepción de Mercadería (SGIM) se definieron las siguientes etapas de trabajo:

#### 

* #### Etapa 1. Análisis del problema



Se identificó la situación actual del establecimiento, analizando los procesos relacionados con la recepción de mercadería, el control del inventario, la organización de los productos y la gestión de la documentación. Esta etapa permitió reconocer las principales necesidades del negocio.



* #### Etapa 2. Definición de objetivos



Con base en el análisis realizado, se establecieron el objetivo general y los objetivos específicos que orientan el desarrollo de la propuesta conceptual.



* #### Etapa 3. Diseño de la propuesta



Se planteó una solución tecnológica conceptual mediante el Sistema de Gestión de Inventario y Recepción de Mercadería (SGIM), definiendo sus principales funcionalidades, alcance y requerimientos.



* #### Etapa 4. Documentación del proyecto



Toda la información del proyecto se organizó en archivos Markdown (.md) y de texto (.txt), manteniendo una estructura clara y ordenada para facilitar su consulta.



* #### Etapa 5. Control de versiones y trabajo colaborativo



La documentación fue gestionada mediante Git y GitHub, utilizando commits para registrar los avances, ramas para desarrollar nuevas secciones del proyecto y Pull Requests para integrar los aportes realizados durante el trabajo colaborativo.

#### 

* #### Resultado esperado



Al finalizar el proyecto se dispone de una propuesta conceptual organizada y documentada, acompañada de un historial de versiones que evidencia el proceso de desarrollo y la aplicación de buenas prácticas en el uso de Git y GitHub.
