# Reflexión



El desarrollo de este proyecto me permitió aplicar de forma práctica los conocimientos adquiridos sobre Git y GitHub, comprendiendo la importancia del control de versiones y del trabajo colaborativo en la gestión de proyectos. A través de la creación del repositorio, el uso de ramas, los commits y los Pull Requests, pude organizar la documentación y registrar de manera ordenada la evolución del proyecto.



Durante la actividad también enfrenté algunos inconvenientes relacionados con la sincronización entre el repositorio local y el remoto y con la integración de ramas. Resolver estas situaciones utilizando herramientas y comandos de Git fortaleció mi comprensión sobre el flujo de trabajo y la importancia de mantener el repositorio actualizado.



En conclusión, esta experiencia fortaleció mis habilidades en el uso de Git y GitHub, permitiéndome comprender cómo estas herramientas facilitan la organización, el seguimiento de cambios y el trabajo colaborativo en proyectos de desarrollo.
