# Requerimientos



#### Requerimientos funcionales



Los requerimientos funcionales describen las principales funciones que debería cumplir el Sistema de Gestión de Inventario y Recepción de Mercadería (SGIM).



* RF1: El sistema deberá registrar la recepción de mercadería proveniente de los proveedores.



* RF2: El sistema deberá actualizar automáticamente el inventario al registrar el ingreso de nuevos productos.



* RF3: El sistema deberá permitir consultar la disponibilidad de los productos almacenados.



* RF4: El sistema deberá registrar las fechas de vencimiento de los productos perecibles y facilitar su seguimiento.



* RF5: El sistema deberá almacenar la información relacionada con facturas, guías de remisión y demás documentos asociados a cada recepción de mercadería.



* RF6: El sistema deberá generar reportes básicos sobre el estado del inventario y los productos próximos a vencer.



#### Requerimientos no funcionales



Los requerimientos no funcionales establecen las características de calidad que debería cumplir la solución propuesta.



* RNF1: La información deberá mantenerse organizada y disponible para su consulta.



* RFN2: El sistema deberá ofrecer una interfaz sencilla y fácil de utilizar por el personal del establecimiento.



* RFN3: La información registrada deberá mantenerse protegida mediante mecanismos básicos de acceso.



* RFN4: La solución deberá facilitar la consulta rápida de la información para apoyar la toma de decisiones.



* RFN5: El sistema deberá permitir el crecimiento futuro mediante la incorporación de nuevas funcionalidades, si el establecimiento lo requiere.
