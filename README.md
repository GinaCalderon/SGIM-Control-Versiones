# Sistema de Gestión de Inventario y Recepción de Mercadería (SGIM)



#### Descripción:



Este repositorio contiene la documentación de una propuesta para desarrollar un Sistema de Gestión de Inventario y Recepción de MAERCADERÍA (SGIM), cuyo propósito es optimizar el control de los productos, mejorar el registro de mercadería y facilitar la administración del inventario en un establecimiento comercial.



Como parte del proyecto se aplican buenas prácticas de desarrollo colaborativo utilizando Git y GitHub, incluyendo el uso de ramas, Commits, Pull Requests y documentación en archivos Markdown (.md) y texto (.txt).





#### Objetivo del repositorio:



Documentar de forma organizada todas las etapas del proyecto, permitiendo llevar un control de versiones y facilitar el trabajo colaborativo ente integrantes del equipo.





#### Estructura:



* ###### Problema.md



Análisis del problema identificado.

Objetivo general y objetivos específicos.



* ###### Alcance.md



Alcance y limitaciones del proyecto.



* ###### Requerimientos.md

Planificación conceptual del proyecto.



* ###### Integracion\_de\_Aportes.md
