# Objetivos

# 

#### Objetivo general



Diseñar de manera conceptual un Sistema de Gestión de Inventario y Recepción de Mercadería (SGIM) que contribuya a mejorar el control del inventario, la recepción de productos y la organización de la información en el establecimiento comercial "I Love Gifts", documentando el proyecto mediante Git y GitHub como herramientas de control de versiones y trabajo colaborativo.



#### Objetivo específicos



* Analizar las dificultades presentes en los procesos de recepción de mercadería, control de inventario y gestión documental del establecimiento.



* Plantear una propuesta tecnológica conceptual que contribuya a optimizar la administración del inventario y la recepción de productos.



* Definir el alcance y los requerimientos del proyecto para establecer las funcionalidades esperadas de la solución propuesta.



* Documentar el desarrollo del proyecto utilizando archivos Markdown (.md) y de texto (.txt).



* Aplicar el uso de Git y GitHub mediante commits, ramas y Pull Requests para gestionar el control de versiones y la integración de aportes.
