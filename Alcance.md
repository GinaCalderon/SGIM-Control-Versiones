# Alcance



#### Alcance del proyecto



El presente proyecto tiene como alcance el análisis de la problemática relacionada con la gestión del inventario y la recepción de mercadería en el establecimiento comercial "I Love Gifts", así como el diseño conceptual de una solución tecnológica que contribuya a mejorar estos procesos.



La propuesta contempla la definición de los objetivos, requerimientos, funcionalidades y planificación general del Sistema de Gestión de Inventario y Recepción de Mercadería (SGIM), además de la documentación del proyecto mediante Git y GitHub utilizando archivos Markdown (.md) y de texto (.txt).



#### Limitaciones



Este proyecto no incluye el desarrollo de una aplicación informática ni la implementación de una base de datos. Tampoco contempla el diseño de interfaces, programación, pruebas de funcionamiento o la puesta en marcha del sistema.



Su finalidad es presentar una propuesta conceptual y demostrar la aplicación de buenas prácticas de control de versiones, documentación y trabajo colaborativo mediante el uso de Git y GitHub.
